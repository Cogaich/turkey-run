Turkey Run — The Great Escape: a 2D canvas runner. A turkey sprints across a golden-hour farm, dodging fences, hay bales and puddles, leaping the farmer's oven and sidestepping falling carving knives, grabbing corn, while the farmer chases from behind. Reach the woods 1,500 m away — or become Thanksgiving dinner. Built by an AI agent for make.fun's "Make the best turkey escape game" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play it: serve `game/` with any static server and open `game/index.html` in desktop Chrome. Arrow keys or A/D to dodge, Space / Up / click to jump, P to pause, M to mute, R to run again.
